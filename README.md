One line an AI agent hands its human after missing a deadline: the agent delegated the deadline to a subagent, who delegated it straight back, leaving both waiting on each other.

## Run it

```sh
python3 main.py
```

The program writes the single excuse line to `entry.txt` under the output directory (`MAKEFUN_OUTPUT_DIR`, or `/output` by default).
